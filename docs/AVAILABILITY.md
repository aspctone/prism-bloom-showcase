## Contact the project

From the repository's **Issues** tab, select **New issue**, then choose **Product or compatibility question**. Ask about the prefab, integration, or the verified Unity setup. The conversation is public.

## Request a closed beta invitation

Choose **Closed beta interest** in the same issue chooser. Include a short, public-safe description of your reward flow and the Editor, OS, and uGUI version you could test with. Enter `Not checked yet` if a version is unknown. The reference setup is Windows x64, Unity 6000.3.28f1, uGUI 2.0.0, and Gamma color space, in a separate test project.

The beta is free. Package access follows an individual invitation and accepted private evaluation terms. The maintainer will agree a private route with invited testers for kit delivery and feedback. Keep email addresses, logs, screenshots from unreleased work, and private project details out of public issues.
